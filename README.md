# 台本工作室

广播剧台本。用来排稿、改稿、导出稿，不做语音合成。

打开就能写导演本。角色卡、世界书和用户人设分开保存。生成稿单独存放，确认后再采用。配音稿只留人声，导出时可以选择完整本、纯人声，或按角色拆开。

## 使用

用浏览器打开 `index.html`。

1. 左上角「项目」可以新建、切换。右上角「备份」可以下载或导入整个项目。备份文件里有接口密钥，不要发给别人。
2. 「预设」选择文风和结构。「角色」「世界书」「人设」分别填写或导入 txt、docx。
3. 「生成」填写接口地址、模型和密钥。生成稿可以修改、删除和分类。点「采用」后，才替换当前稿里没有锁定的行。
4. 「配音稿」可以临时去掉某一行，并复制人声稿。
5. 导出前勾选格式。长篇可以勾选要放进同一个文件的集。

平台标签写在台词里，例如 `妈妈，(轻笑)我饿了。` 底部「教程」里有模板。勾选「平台标签」后，只替换纯人声 TXT 和按角色拆开的 TXT。

数据保存在这台浏览器里。清理浏览器数据前，先从右上角下载备份。

## 自己部署

这是静态页面，不需要构建，也不需要服务器程序。

- 本机：直接打开 `index.html`。
- 网站：把整个目录上传到任意静态空间，保证 `index.html`、js、css 和 `manifest.webmanifest` 在同一层。用 HTTPS 打开。
- 手机桌面：用浏览器打开后，选择「添加到主屏幕」。图标使用同目录下的 `icon-192.png` 和 `icon-512.png`。没有这两张图片也可以使用。更换图标后，删掉旧的桌面图标，再添加一次。

接口密钥由用户填写在自己的浏览器里，部署者不要写进文件。

## 图标

想换桌面图标时，把 PNG 放在和 `index.html` 同一层：

- `icon-192.png`：192×192
- `icon-512.png`：512×512

没有这两个文件时留空，不影响使用。
